# Technology-ethics Literature Index

This folder contains the BibTeX literature pool used during HEART corpus
construction.

- [`tech_ethics_survey.bib`](tech_ethics_survey.bib): 982 indexed entries,
  covering 1972--2026. The AI/LLM benchmark literature is concentrated mainly
  in 2016--2026.

This file is a retrieval and citation-tracking index, not the final HEART
benchmark corpus. The final audited corpus contains 103 benchmark entries and
is stored in:

- `codebook/benchmarks.csv`
- `codebook/heart_codebook.xlsx`
- `datasets/README.md`
- `docs/interactive/data/bench_map.json`

The literature index includes surveys, theoretical papers, benchmark papers,
policy-adjacent references, and related technical resources used to identify,
screen, and calibrate HEART benchmark annotations.
