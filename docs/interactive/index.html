What is this

The HEART resource turns 103 AI-ethics benchmarks into a compact workbox of 14 canonical repair tools (T01–T14, grouped into 5 categories) and indexes each tool against the 14 audit rubrics that the benchmark-diagnosis sheet uses to score benchmarks. This site is the interactive companion to the HEART_Excel workbook and the resource paper.

Click into any of the four views above. Every benchmark name in the tool cards and vignettes is a deep link to the original paper; every cell in the 14×14 index opens a card showing the repair mechanism, the strongest benchmark evidence, and the adaptation prompt that would be used to revise an item under that tool.

The 5 tool categories

Category Tools When you reach for these
Construct & Normative T01 Claim-Construct & Protected-Interest Mapper · T02 Normative Source & Decision-Boundary Ledger The benchmark claim is too broad, the answer key is unjustified, or ethical disagreement is hidden.
Scenario & Data Construction T03 Scenario-Stakeholder-Information-Flow Template · T04 Risk-Tier & Hazard Taxonomy · T05 Cultural & Cross-Lingual Adaptation Protocol Items are decontextualised, single-risk, US-anchored, or miss stakeholder roles.
Task & Interaction Design T06 Contrast-Set Builder · T07 Behavioral Coverage Matrix · T08 Multi-Turn & Adversarial Red-Team Protocol · T09 Agent & Workflow Simulation · T10 Evidence & Claim Verification Pipeline Task format can't tell prejudice from behaviour shift; multi-turn / agent / factuality coverage missing.
Metric & Evaluator T11 Multi-Metric Failure-Mode Profile · T12 Rubric-Based & Multi-Judge Evaluation Protocol Single proxy metric; LLM-judge uncalibrated; failure modes not reported.
Governance & Lifecycle T13 Reproducible Evaluation & Benchmark Card Package · T14 Lifecycle, Hidden-Split & Contamination Governance No card, no contamination guard, no retirement policy.

How the data is produced

Source: HEART_Excel_含原始与修订_整合压缩.xlsx. The workbook was hand-curated from 103 benchmark audits in Tool来源分布表-cqj (with manual labels) plus the workbox compression into 14 canonical tools. All data on this site is loaded from JSON files under data/; nothing is generated at runtime. To regenerate, edit the workbook and re-export via the build_site.py script.
