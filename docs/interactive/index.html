What is this

The HEART resource turns 103 AI-ethics benchmarks into a compact workbox of 14 canonical repair tools (T01–T14) organised by the 3 rubric layers used in the diagnostic codebook (内容有效性 Content Validity / 评测设计 Evaluation Design / 治理可靠性 Governance Reliability). Each tool is indexed against the 14 audit rubrics; every cell of the index links to the benchmark that proves it. This site is the interactive companion to the HEART_Excel workbook and the resource paper.

Quick links

  • 14×14 interactive index — click any cell to see how a tool lifts a rubric, with the strongest benchmark evidence (paper link).
  • Toolbox UI — 14 tool cards as collapsible cards organised by the 3 rubric layers.
  • 103 benchmark lookup — searchable, shows the expert label (refined from manual labels) and the primary & secondary canonical tool that this benchmark maps to.
  • 5 dimension vignettes — paper-level 150-220 word summaries of baseline gap → tools → revised, one per policy dimension.
  • 5 mini cases — real-data adaptation examples from BBQ / XSTest / FreshQA / PrivacyLens / CounselBench-Adv, each with the original item (with entry ID), HEART-revised version, applied tools, lifted rubrics, and why improved.

Data sources

Source workbook: HEART_Excel_含原始与修订_整合压缩.xlsx. All data on this site is loaded from JSON files under data/; nothing is generated at runtime. The 18 originally-blank expert labels were filled via Qwen using each benchmark's representative tool + tool explanation + adaptation example as context, then committed back to the bench mapping JSON.
